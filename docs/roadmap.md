# Agent CIL 阶段计划与验收标准

## 目标与工作方式

- **仅开发 `agent-cil` 命令行程序**：以 2.1.88 作为重构基线，2.1.304 作为升级目标；不开发 Renderer、Desktop UI 或平台客户端。
- **成熟源码优先**：弄清真实调用链和依赖后，优先移植已有、确有使用权的 `package/` 与 `restored-src/` 实现；不重复开发通用 Agent Runtime，不强行保留价值不足的自建模块。
- **授权与验证并重**：核实原始许可、使用/修改/再分发权限，保留必要版权声明。公开可读或保存在自有账户下，并不自动证明第三方版权已获许可。
- **每次功能修复都有行为回归与 GitHub Actions 验证**；优先可安装、可运行、能完成任务的 CLI，而不是持续扩张逆向文档或平台功能。
