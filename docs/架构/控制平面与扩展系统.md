# 控制平面与扩展宿主

## 1. Control Plane

Command Bus 接收外部控制命令，Session Controller 验证命令是否符合当前状态，再追加事件并驱动 Agent Loop。

核心命令：

- StartTurn；
- SteerTurn；
- QueueFollowUp；
- InterruptTurn；
- RespondApproval；
- ResumeThread；
- ForkThread。

命令请求和领域事件是不同对象：Command 表达意图，Event 记录已接受并提交的事实。

## 2. Steering / Follow-up / Interrupt

| 动作 | 行为 | 边界 |
| --- | --- | --- |
| Steer | 在当前安全边界后插入新指令，影响当前 Turn 后续工作 | 不直接修改已经提交的模型或工具历史 |
| Follow-up | 当前 Turn 完成后开始一个新的 Turn | 保留独立 turnId |
| Interrupt | 请求取消当前 Turn，停止尚未开始的工作并安全收尾 | 不声称撤销已发生的副作用 |

这些行为由 Session Controller 管理，CLI 只负责把用户输入转成命令。

## 3. Approval 生命周期

- Tool Runtime 生成 Approval Request。
- Session Controller 持久化待审批状态。
- Host 展示审批内容。
- 用户通过 RespondApproval 返回决定。
- Runtime 校验 approvalId、toolCallId、输入摘要和授权范围。
- 过期、重复或与当前输入不匹配的审批响应必须拒绝。
- Turn 在等待审批期间可以被 Interrupt。

## 4. Extension Host

可扩展组件包括：

- Model Provider；
- Context Strategy；
- Session Store / Event Store；
- 原生工具和 MCP 工具；
- Skills；
- Hooks；
- Host-specific Approval / Workspace Adapter。

插件启动时声明依赖和版本约束。Extension Host 验证依赖后按拓扑顺序加载；卸载时撤销注册、移除监听器、停止子进程并释放资源。

## 5. 插件不可覆盖的核心

以下能力不能被插件替换或绕过：

- Thread / Turn / Step 状态机；
- Event Journal 提交语义；
- Execution Guard 统一入口；
- 权限二次校验；
- Sandbox 强制边界；
- ToolCall ID 和结果配对；
- 取消与恢复语义。

架构开放不代表执行规则失控。

## 6. MCP 边界

MCP 是外部工具协议和传输适配，不应成为内核状态管理机制。MCP 工具与原生工具共用 Tool Runtime 和 Execution Guard。

若使用宿主进程内的 MCP Handler，需要分别维护外层 Control Request ID 与内层 JSON-RPC ID。外层请求取消不应误取消其他 MCP 调用；普通 stdio / HTTP MCP Server 与宿主内存桥接应作为不同 Transport 建模。
